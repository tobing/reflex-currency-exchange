# Currency Exchange Rate

A simple full-stack currency exchange application built with Reflex as a hands-on project to learn the framework. <br> 
The project focuses on web application development using pure Python. <br>
The main code on [`exchange.py`](exchange/exchange.py) and theme config on [`rxconfig.py`](rxconfig.py). <br>

# **DEMO** [Click here](https://currency.tobingbox.top/)

# Stack
  - Reflex framework [https://reflex.dev/](https://reflex.dev/). Write in python compile down React frontend app and FastAPI backend app
  - Currency exchange rate [https://frankfurter.dev/](https://frankfurter.dev/) 
  - Geolocation detection [https://ip-api.com/](https://ip-api.com/)



## Prerequisite
[uv](https://docs.astral.sh/uv/getting-started/installation)
<br>

## Start & Run
```
git clone https://github.com/tobing/reflex-currency-exchange.git
cd reflex-currency-exchange
uv sync
uv run reflex run
```

**Windows**: Allow Python and Bun through the firewall when prompted.
